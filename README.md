# Draconia: Zephyrion — Demo

**[▶ Play in your browser](https://lassandriel.github.io/draconia-demo/)**

You are Zeph, the fastest flier in Luxana, carrying messages for the imperial
palace. Fly freely through the sun palace, talk to its residents and take on
their tasks.

> **Note:** The game is currently only available in **German**. An English
> version may follow later.

This is an early demo and a work in progress. Things will change, and some
things may not work yet.

## Controls

| Key | Action |
|---|---|
| `WASD` / arrow keys | fly and walk; ↓ drops through ledges |
| `E` | use: open/close doors, pick up, talk |
| `Space` | gust of wind (once learned), aim with the arrow keys |
| `M` | map (mouse wheel / + − zooms, drag to move); pauses the game |
| `Esc` | pause menu |
| `R` | back to the start point |

Your progress saves itself and stays in your browser. It is not shared
between devices.
