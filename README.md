# Draconia: Zephyrion — Demo

**[▶ Play in your browser](https://lassandriel.github.io/draconia-demo/)**

A stealth game in the world of Draconia — one where you fly a lot.

You are Prince Zeph, the fastest flier in Luxana. Fly freely
through the sun palace, slip past guards and servants, put out lights to stay
unseen, and talk to the residents to take on their tasks.

> **Language:** The game is currently only available in **German**. An English
> version may follow later.

> **Graphics:** Everything you see is a placeholder. The final art will be
> drawn by hand.

This is an early demo and a work in progress. Things will change, and some
things may not work yet.

## Controls

Keyboard and gamepad both work. No installation, nothing to download.

| Keyboard | Gamepad | Action |
|---|---|---|
| `WASD` / arrow keys | stick | fly and walk |
| `↓` `↓` (double tap) | `↓` + `A` | drop through a walkway |
| `Shift` | `RB` | sprint in flight — fast, but loud |
| `E` | `A` | use: doors, lights, pick up, talk, pet animals |
| `Space` | `X` | gust of wind (once learned), aim with the arrow keys |
| `M` | `View` | map (mouse wheel / + − zooms, drag to move); pauses the game |
| `Esc` | `Menu` | pause menu |
| `R` | | back to the last checkpoint |

Your progress saves itself and stays in your browser. It is not shared
between devices.
